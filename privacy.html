Privacy Policy

Bit Mechanic Uploader. Last updated 26 November 2026.

What the app is

Bit Mechanic Uploader is a private tool used only by the owner of the Bit Mechanic YouTube channel to upload and schedule the channel's own videos. It has no other users.

What data it uses

With the owner's permission, the app uses the YouTube Data API to upload videos, set their titles, descriptions, thumbnails and publish times, and add them to the channel's own playlists. It reads the channel's own details only to make sure it is uploading to the right channel.

What it stores

The sign-in token is stored only on the owner's own computer. The app does not collect, sell or share personal data, does not track anyone, and sends nothing to any service other than YouTube.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Through the Bit Mechanic YouTube channel.
